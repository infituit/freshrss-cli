# Project Skills

本目录保存已经由 `freshrss-cli` 真实仓库材料支撑的项目级工作技能。没有足够代码、模板、流程或验证证据时，不提前创建技能。

## Skill Index

| Skill                                   | 适用场景                                            |
| --------------------------------------- | --------------------------------------------------- |
| `freshrss-cli-create-pr`                | 按本项目贡献规范、PR 模板和验证矩阵准备或创建 PR    |
| `freshrss-cli-audience-boundary`        | 按使用者、贡献者、集成者和 Agent 区分文档内容边界   |
| `freshrss-cli-information-architecture` | 决定 README、docs、skills、Issue 和临时记录的归属   |
| `freshrss-cli-testsuite-support`        | 使用隔离的 FreshRSS Docker Compose 集成测试 fixture |

## 触发原则

- 先读取目标路径附近的项目规则和已有实现，再应用技能。
- 只加载与当前任务直接相关的技能。
- 项目技能只约束 `freshrss-cli` 的工作方式，不改变 FreshRSS API 的外部契约。
- 任何远程 GitHub 写操作都必须获得用户明确授权。
- 新技能必须先有对应的本项目代码、文档、模板或实际工作流作为证据。
